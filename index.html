Auf „Sichern“ tippen → „Bild sichern“. Oder das Bild lange gedrückt halten → „Zu Fotos hinzufügen“.

2. Texte zum Einfügen

3. Karte in Wallet legen

  1. Sichere oben das Banner in Fotos.
  2. Öffne Wallet und tippe oben rechts auf +.
  3. Wähle „Pass erstellen“ und dann „Manuell erstellen“.
  4. Wähle als Bild das Banner aus deinen Fotos.
  5. Trag die Texte ein (oben auf „Kopieren“ tippen, dann einfügen). Als Code nimmst du den QR-Inhalt.
  6. Feld für den großen Text leer lassen. Chip, Nummer und Name sind schon im Banner.
  7. Speichern – fertig. Die Karte liegt jetzt in Wallet.
  8. Kein „Pass erstellen“ zu sehen? Dann hast du noch kein iOS 27 (Einstellungen → Allgemein → Softwareupdate) – oder nimm einfach Pass2U. Die Knöpfe können bei dir auch etwas anders heißen.
  1. Lade „Pass2U Wallet“ aus dem App Store (kostenlos).
  2. Sichere oben Banner, Logo und Icon in Fotos.
  3. In Pass2U auf + tippen und einen neuen Pass erstellen. Als Art „Kundenkarte“ / „Store Card“ wählen.
  4. Bilder: Strip = Banner, Logo = Logo, Icon = Icon.
  5. Farben: Hintergrund, Text und Titel mit den Farbcodes von oben (z. B. ).
  6. Felder: Primär = großer Text, Sekundär = Feld 1 und Feld 2, Logo-Text = Kartenname.
  7. Felder: Primär leer lassen (sonst steht Text über dem Chip), Sekundär = Feld 1 und Feld 2, Logo-Text = Kartenname.
  8. Barcode: QR-Code wählen und den QR-Inhalt einfügen – oder keinen Barcode.
  9. Speichern → „Zu Apple Wallet hinzufügen“.
  10. Die Knöpfe in Pass2U können je nach Version etwas anders heißen – das Prinzip bleibt gleich.

Hinweis: Das ist eine eigene Karte in Wallet – bezahlen kann man damit nicht. Das Bild einer echten Bankkarte kann keine App ändern.
